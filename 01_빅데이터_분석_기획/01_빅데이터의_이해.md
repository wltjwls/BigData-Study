# 빅데이터 분석 기획
## 빅데이터의 이해 

### **빅데이터 개요 및 활용**
#### 데이터의 구분 
1. 정량적 데이터: 주로 숫자로 이루어진 데이터

    ex. 2020년, 100km/h 등
2. 정성적 데이터: 문자와 같은 텍스트로 구성. 함축적 의미

    ex. 철수가 시험에 합격하였다.

#### 데이터의 유형 
1. 정형 데이터 
2. 반정형 데이터 (ex. JSON, XML, HTML, RDF)
3. 비정형 데이터 (ex. 동영상, 이미지, 음성)


#### 데이터의 근원에 따른 분류 
1. 가역 데이터

    - 1:1 관계
    - 이력 추적 가능
    - 변경사항 반영 가능

2. 불가역 데이터

    - 원본으로 환원 불가능 
    - 변경사항 반영 불가능

#### 데이터의 기능
1. 암묵지 

    - 개인에게 체계화 되어있으며, 외부에 표출되지 않은 무형의 지식 
    - 전달과 공유가 어려움

2. 형식지

    - 형상화된 유형의 지식
    - 전달과 공유가 쉬움 

#### 지식창조 매커니즘 
1. 공통화 
2. 표출화
3. 연결화
4. 내면화 

#### 데이터, 정보, 지식, 지혜
- 지식의 피라미드(가치창출 프로세스)
1. 데이터
2. 정보
3. 지식
4. 지혜 

#### 데이터베이스란?
- 개별적으로 접근하거나 검색할 수 있는 독립된 저작물

#### 데이터베이스 관리 시스템 (DBMS)
- 데이터를 관리하며 응용 프로그램들이 데이터베이스를 공유하며 사용할 수 있는 환경을 제공하는 소프트웨어

    - 관계형 DBMS
    - 객체지향 DBMS
    - 네트워크 DBMS
    - 계층형 DBMS
- SQL(Structured Query Language)

    - 질의 기능, 데이터 정의와 조작 기능 

#### 데이터베이스의 특징 
1. 통합된 데이터
2. 저장된 데이터
3. 공용 데이터
4. 변화하는 데이터 

#### 데이터베이스의 활용 
1. OLTP (갱신 위주)
2. **OLAP** (조회 위주)

#### 데이터 웨어하우스 (DW)
- 데이터 웨어하우스의 특징

    - 주제지향성
    - 통합성
    - 시계열성
    - 비휘발성 

#### 빅데이터 개요
- 방대하여 기존의 방법이나 도구로 수집/저장/분석 등이 어려운 정형 및 비정형 데이터들을 의미 
- 일반적은 데이터베이스 소프트웨어로 저장, 관리, 분석할 수 있는 범위를 초과하는 규모의 데이터
- 저렴한 비용으로 가치를 추출. 차제대 기술 및 아키텍처 
- **새로운 통찰이나 가치를 추출** 

#### 빅데이터 등장으로 인한 변화
- 사전처리 -> **사후처리**
- 표본조사 -> **전수조사**
- 질 -> **양**
- 인과관계 -> **상관관계**

#### 가트너의 3V
- 규모 (volume)
- 유형 (Variety)
- 속도 (Velocity)

+2V

- 품질(Veracity)
- 가치 (Value)

#### 빅데이터 활용을 위한 3요소 
- 자원 [빅데이터]
- 기술 [빅데이터플랫폼, AI]
- 인력 [알고리즈미스트, 데이터사이언티스트]

#### 빅데이터의 기능과 효과 
- 고객 세분화와 맞춤형 개인화 서비스 제공
- 알고리즘 기반으로 의사결정 지원 

#### 빅데이터의 가치 측정의 어려움 
- 데이터 활용 방식 (언제, 어디서 활용할지 알 수 없음)
- 가치 창출 방식 (기존에 없던 가치를 창출할 수도 있어 사전에 측정하기 어려움)
- 분석 기술 발전 (새로운 분석 기법이 등장할 경우 큰 가치를 찾을 수도 있음)
- 데이터 수집 원가 (목적에 따라 비용이 상황에 따라 달라질 수 있음)

#### 데이터 산업의 진화 
1. 데이터 처리 시대 

    - EDPS 도입 
    - 업무 처리의 대상으로 새로운 가치를 제공 X

2. 데이터 통합 시대

    - 데이터 모델링과 데이터베이스 관리 시스템 등장 
3. 데이터 분석 시대

    - 하둡, 스파크 등의 빅데이터 기술 등장 
4. 데이터 연결 시대
5. 데이터 권리 시대 

    - 자신의 데이터에 대한 권리 보유
    - 스스로 행사할 수 있어야 한다는 마이데이터(My Data)등장 

#### 데이터 산업의 구조
- 인프라 영역
- 서비스 영역 

#### 데이터 분석 업무 수행 주체에 따른 조직구조 
- 집중형
- 기능형
- 분산형 

#### 데이터 사이언스 
- 정형, 비정형 형태를 포함한 다양한 데이터로부터 지식과 인사이트를 추출하는 데 과학적 방법론, 프로세스, 알고리즘, 시스템을 동원하는 융합분야 
- 데이터 사이언스의 한계

    - 가정과 같이 인간의 해석이 개입되는 단계 불가피
    - 사람에 따라 서로 다른 해석과 결론
    - 모든 분석은 가정에 근거 

#### 데이터 사이언티스트 
- Hard Skill 

    - 빅데이터에 대한 이론적 지식
    - 분석 기술에 대한 숙련

- Soft Skill

    - 통찰력 있는 분석 
    - 설득력 있는 전달
    - 다분야 간 협력
